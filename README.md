# Sign Language Recognition with CNNs

**Final Year Project — Applied Mathematics in Sign Language Recognition using Convolutional Neural Networks**

Real-time sign language gesture classification system built as part of an Industrial Mathematics degree.

---

### Overview

This project applies deep learning (CNNs / MobileNetV2) and computer vision techniques to classify sign language gestures, with the goal of improving accessibility through automated recognition and speech output.

Related implementation work also lives in the main journey repo:

→ [Sign_Lang_using_gTTS.ipynb](https://github.com/DATAITINA/my-ai-journey/blob/main/Sign_Lang_using_gTTS.ipynb)

---

### Key Components

- CNN-based image classification
- MobileNetV2 architecture
- MediaPipe hand tracking
- Real-time webcam pipeline
- Speech output (gTTS)
- 7 gesture classes

---

### Pipeline

```
Webcam → Hand Tracking (MediaPipe) → Image Processing → CNN Classification → Gesture Label → Speech Output
```
